# Dissolving the party cabinet.
#
# Called by SWE_coalition_war_cabinet. A national unity government is not a
# reshuffle - every party minister leaves, and the three political advisor
# slots are emptied so the war cabinet can be built from scratch.
#
# THERE IS NO remove_all_advisors EFFECT. HoI4 has no way to clear a slot
# generically: remove_advisor_role strips the ROLE from a character, which is
# permanent and wrong here, and the only way to un-hire somebody is
# remove_ideas on the idea their advisor entry is registered under. So this
# walks the whole Swedish political advisor roster by name.
#
# EVERY REMOVAL IS GUARDED. remove_ideas on an idea the country does not hold
# writes an error to the log for every name that is not currently seated, and
# at most three of these ever are.
#
# GENERATED FROM common/characters/SWE.txt plus this mod's own two ministers.
# If a future patch adds a Swedish political advisor, add it here too or the
# war cabinet will quietly leave that one minister in office.
