# Trade laws, locked for Russian warlord states.
#
# WHY THIS FILE EXISTS. A warlord is forced onto Closed Economy in
# common/on_actions/wif_on_actions.txt, but that grant alone is only
# enforcement: the player could still switch away and simply be put back a week
# later, having wasted the political power. To grey the option out instead, the
# OTHER trade laws have to refuse warlords, and an idea's available block cannot
# be appended to from outside - the whole idea has to be redefined.
#
# So every trade law except closed_economy is reproduced here VERBATIM from
# vanilla common/ideas/_economic.txt, with exactly one line added to each:
#
#     NOT = { has_idea = wif_russian_warlord }
#
# NOTHING ELSE IS CHANGED, and nothing else should be. If a patch alters a trade
# law, this file silently keeps the old version - so on a vanilla update, diff
# this against _economic.txt and re-copy rather than hand-editing.
#
# closed_economy is here too, but for the opposite reason and with a DIFFERENT
# addition: it gets allowed_to_remove rather than an available guard, because
# warlords must be able to hold it and unable to drop it. Its available block is
# vanilla's, untouched.
#
# The filename is NOT _economic.txt on purpose. That name would replace the
# vanilla file wholesale and delete every economy law, trade law and idea in it.
# A distinct filename merges into the same groups instead.

			# The other seven trade laws refuse warlords in their available
